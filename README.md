# FindMyCourse.com

FindMyCourse.com is a course recommendation tool. Tell it what you want to learn, your background, and a few preferences, and it returns the top matching courses pulled from Coursera, edX, Udemy, and Udacity.

## How it works

The recommendation engine combines two signals:

1. A semantic search over course titles, descriptions, and skills using sentence embeddings.
2. A graph neural network trained on course relationships (shared skills, prerequisite structure, and topic similarity), refined with a contrastive learning objective so that related courses end up close together in the embedding space.

The result is a ranked list of courses that considers not just keyword overlap, but how closely each course actually aligns with what you are looking for.

## Features

* Search by topic, for example "cybersecurity" or "introduction to machine learning"
* Filter by degree level, study level, platform, cost, and duration
* Add optional context, such as a specific concept or format you want covered
* Returns the top 5 matches with platform, level, cost, duration, and a link to each course

## Getting started

### 1. Get the data files

The app needs four files placed inside `backend/data/`:

* `unified_courses.csv`
* `course_embeddings.npy`
* `contrastive_embeddings.npy`
* `node_index_with_clusters.csv`

These are generated by the model training pipeline and are not included in this repository, since they are large binary files rather than source code.

### 2. Set up the backend

```bash
cd backend
python -m venv venv
source venv/bin/activate        # on Windows Git Bash: source venv/Scripts/activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

The first run downloads a small open source sentence embedding model (about 90MB). Once you see a message that the server is ready, leave it running.

You can confirm it started correctly by opening `http://localhost:8000/health` in a browser.

### 3. Open the frontend

Open `frontend/index.html` directly in your browser. No build step or server is required for the frontend itself. Fill in the form and submit to see recommendations from your local backend.

## Tech stack

* Backend: Python, FastAPI, Sentence Transformers, scikit learn, PyTorch Geometric
* Frontend: HTML, CSS, and vanilla JavaScript
* Model: Graph convolutional network with MinCut pooling and a contrastive loss, trained on a graph of over 20,000 courses

## Notes

If the frontend cannot reach the backend, the app will show a message asking you to check that the backend server is running on port 8000. Update the `API_BASE` value near the top of `frontend/script.js` if you run the backend on a different address or port.
