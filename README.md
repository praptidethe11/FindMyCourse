# FindMyCourse.com

FindMyCourse.com is a course recommendation tool. Tell it what you want to learn, your background, and a few preferences, and it returns the top matching courses pulled from Coursera, edX, Udemy, and Udacity.

## How it works

The recommendation engine combines three signals:

1. A semantic search over course titles, descriptions, and skills using sentence embeddings, used both to interpret the query and as a direct relevance score.
2. A graph neural network trained on course relationships (shared skills, prerequisite structure, and semantic similarity), refined with a contrastive learning objective so that related courses end up close together in the embedding space.
3. An XGBoost model trained to predict whether two courses are meaningfully linked, using features derived from the graph (contrastive similarity, shared skills, cluster membership, level difference, platform match). This model was tuned with Bayesian optimization (Optuna) and validated on held-out graph edges the model never saw during training, so its reported accuracy reflects genuine generalization rather than memorization.

The result is a ranked list of courses that blends direct topic relevance with structural signal from the course graph, so recommendations stay grounded in what was actually searched for rather than drifting toward whatever cluster the query happens to land in.

## Features

- Search by topic, for example "cybersecurity" or "introduction to machine learning"
- Filter by degree level, study level, platform, cost, and duration
- Add optional context, such as a specific concept or format you want covered
- Returns the top 5 matches with platform, level, cost, duration, and a link to each course
- Free/paid filtering only returns courses with confirmed pricing — courses with unknown pricing are never silently included when a "free" or "paid" filter is applied

## Getting started

### 1. Get the data files

The app needs these files placed inside `backend/data/` and `backend/models/`:

In `backend/data/`:

- `unified_courses.csv`
- `course_embeddings.npy`
- `contrastive_embeddings.npy`
- `node_index_with_clusters.csv`

In `backend/models/`:

- `link_predictor_xgb.json`

These are generated by the training pipeline in `backend/src/` (or the reference notebook in `backend/notebooks/`) and are not included in this repository, since they are large binary files rather than source code.

### 2. Set up the backend

```bash
cd backend
python -m venv venv
source venv/bin/activate        # on Windows Git Bash: source venv/Scripts/activate
pip install -r requirements.txt
uvicorn main:app --reload --port 5500
```

The first run downloads a small open source sentence embedding model (about 90MB). Once you see a message that the server is ready, leave it running.

You can confirm it started correctly by opening `http://localhost:8000/health` in a browser.

### 3. Open the frontend

Open `frontend/index.html` directly in your browser. No build step or server is required for the frontend itself. Fill in the form and submit to see recommendations from your local backend.

## Tech stack

- Backend: Python, FastAPI, Sentence Transformers, scikit-learn, PyTorch Geometric, XGBoost, Optuna, SHAP
- Frontend: HTML, CSS, and vanilla JavaScript
- Model: Graph convolutional network with MinCut pooling and a contrastive loss, trained on a graph of over 19,000 courses, paired with a Bayesian-tuned XGBoost link predictor for final ranking

## Model evaluation

The link predictor is evaluated on graph edges held out from GNN training, not just held out from the XGBoost split, so reported metrics reflect genuine generalization to unseen course relationships:

- AUC-ROC: ~0.997, PR-AUC: ~0.997 on held-out edges
- Ranking evaluation (top-5 candidates per query course, evaluated against real held-out edges): NDCG@5 ≈ 0.81, Precision@5 ≈ 0.52, Recall@5 ≈ 0.67

Feature importance and SHAP analysis both identify contrastive embedding similarity and shared skill count as the dominant signals driving predictions.

## Notes

If the frontend cannot reach the backend, the app will show a message asking you to check that the backend server is running on port 8000. Update the `API_BASE` value near the top of `frontend/script.js` if you run the backend on a different address or port.

This project is trained on a static snapshot of scraped course-catalog data. It does not currently retrain automatically as courses are added, removed, or re-priced — a production deployment would need periodic re-scraping and retraining to avoid the model's understanding of the course landscape going stale.
